# ข้อสอบ i-Duino R4 กับ Arduino IDE (355 ข้อ)

เว็บฝึกทำข้อสอบปรนัย 355 ข้อ 16 บท พร้อมเฉลยและคำอธิบายทุกข้อ
อ้างอิงจากคู่มือ "แนะนำการใช้งาน i-Duino R4 ด้วยซอฟต์แวร์ Arduino IDE"

- เลือกสอบรายบท (เลือกได้หลายบท) หรือสุ่ม N ข้อจากทุกบท
- จับเวลาได้ (30 / 60 / 90 นาที) ปักธงข้อที่ไม่แน่ใจ มีแผงเลขข้อ
- ดูคะแนนแยกบทเป็นกราฟ ดูเฉลยพร้อมคำอธิบาย และทำใหม่เฉพาะข้อที่ผิด
- เก็บประวัติและแนะนำบทที่ควรทบทวน (เก็บในเบราว์เซอร์ของแต่ละเครื่อง)
- รองรับมือถือ และมีโหมดมืด

เป็นเว็บ static ทั้งหมด (HTML/CSS/JS ล้วน) ดับเบิลคลิก `index.html` เพื่อเปิดในเครื่องได้เลย
วิธี deploy ดูที่ [DEPLOY.md](DEPLOY.md)
